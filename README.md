# Face Recognition Assignment

A Python-based face recognition project using OpenCV.

## Features

- Face detection and recognition
- Recognition of known faces
- Recognition logging
- Annotated output images
- Configurable recognition threshold

## Project Structure

Requirements
Python 3.x
OpenCV
face_recognition
How to Run
Install the required packages:
pip install opencv-python face-recognition
Run the project:
python main.py
